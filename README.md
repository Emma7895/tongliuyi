# Final Project Proposal: Canva Poster Tutorial
## Project Overview
- Platform: Canva (web version)
- Target reader: Student event organizers
- Core tasks:
  1. Create a poster for student academic sharing events.
  2. Export the finished poster as a PDF file.

## Document Plan
1. Write the standalone tutorial `how-to-create-a-canva-poster.md` with clear numbered steps for poster design and PDF export.
2. Add simple troubleshooting tips for common export issues.
3. Keep the previous GitHub tutorial inside the `practice/` folder of this repository.
4. Organize all files with clear names for easy reading.

## Tool Rationale
I choose Canva because it offers ready-to-use templates and a simple drag-and-drop interface, which is friendly for student event organizers without professional design skills. It supports direct PDF export, which matches the common requirement of sharing event materials.
